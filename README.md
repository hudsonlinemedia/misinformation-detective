# The Misinformation Detective

Interactive Brightspace lesson guided by Prof Honey, the noir detective professor.

This GitHub Pages copy includes the four lesson videos in `videos/`. The full SCORM package for Brightspace is built from the same files.

## Archaeology edition

`archaeology/index.html` is a duplicate of the lesson rebuilt from the *Archaeology Detectives: Unearthing the Truth* material (8 files, 42 questions). It keeps its own saved progress, separate from the Health lesson, and reports score and completion to Brightspace when launched as SCORM 1.2.
